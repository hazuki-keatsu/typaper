## 一、操作系统用户接口概述

操作系统提供两类用户接口：

- **系统调用接口**：系统功能调用，供程序使用
- **系统命令接口**：作业控制语言、键盘命令、GUI，供用户直接使用

---

## 二、系统调用（System Call）

### 2.1 基本概念

#### 管态与算态
- **算态（用户态）**：用户程序运行的状态
- **管态（系统态/核心态）**：系统程序运行的状态
- **特权指令**：只允许在管态下使用的指令
  - 有关对外设使用的指令
  - 有关访问程序状态的指令
  - 存取特殊寄存器指令
  - 其他

#### 访管指令
用户程序在算态下运行，无法直接使用外设。**访管指令**的功能：
1. 实现从算态到管态的改变
2. 在管态下由操作系统代替用户完成请求
3. 操作系统完成后由管态返回到算态

#### 广义指令
系统调用是为扩充机器指令、增强系统功能、方便用户使用而提供的，又称为**广义指令**（不同于机器指令）。

- 汇编程序中可直接使用系统调用
- 高级语言中由编译程序将资源操作语句变换为相应的系统调用

### 2.2 系统调用与普通过程调用的区别

| 比较维度 | 系统调用 | 普通过程调用 |
|----------|----------|--------------|
| **调用方式** | 动态调用，程序中不含被调用代码 | 静态调用，被调用代码在同一程序内 |
| **调用地址** | 不固定 | 固定（包含在调用语句中） |
| **返回地址** | 不固定 | 不固定（通过栈保存和弹出） |
| **执行状态** | 核心态和用户态，地址空间不同 | 同一状态 |
| **进入方式** | `int` 或 `trap` 指令 | `call` 或 `jmp` 指令 |
| **与调度关系** | 返回时需检查是否需要重新调度（抢占式系统） | 无关 |
| **嵌套/递归** | 一般不允许在同一进程内嵌套或递归 | 允许 |

**相同点**：
- 改变指令流程
- 可重复执行和共用
- 改变流程后需要返回原处

### 2.3 系统调用类型

| 类型 | 说明 |
|------|------|
| **进程控制** | 进程创建、终止、暂停、挂起等 |
| **进程通信** | 获取消息队列标识、收/发消息、创建共享存储区等 |
| **存储管理** | 内存的申请与释放 |
| **设备管理** | 打开/关闭/读/写设备 |
| **文件保护** | 用户/组标识的获取、设定与改变 |
| **系统管理** | 设置/读取时间、读取用户和主机标识等 |

### 2.4 系统调用的执行过程

#### 使用步骤
1. 将参数和参数首址送到规定的通用寄存器
2. 设置调用指令（访管指令或软中断指令），功能号在指令中或作为参数放入寄存器

#### 执行过程
1. 保护用户程序的"现场"，将系统调用编号、参数放入约定存储单元
2. 根据调用号检查合法性，查系统调用表，转入对应函数
3. 恢复"现场"，将返回参数或参数区首址送到约定寄存器

#### UNIX 实现
- 由自陷指令 `trap` 实现，借助硬件中断机制提供系统核心接口
- 两种使用方式：**直接系统调用** 和 **间接系统调用**

## 三、作业组织和管理

### 3.1 基本概念

- **作业**：用户一次请求计算机系统为它完成任务所进行的工作总和
- **作业步**：处理作业的各个独立子任务
  - 例：编辑 → 汇编 → 链接 → 执行
- **作业流**：多个作业按顺序组成的队列

### 3.2 引入作业管理的原因

- **适用场景**：大型机、网格计算
- **共同属性**：用户数量庞大、耗能巨大、计算节点造价昂贵
- **目标**：提高计算机使用率 → 增加盈利，降低运营成本；灵活控制作业，满足用户需求

### 3.3 作业的组织

作业由三部分组成：
1. **程序**
2. **数据**
3. **作业控制信息**（作业说明书），包括：
   - 作业基本情况
   - 作业控制
   - 资源需求描述

### 3.4 作业类型

| 类型 | 说明 |
|------|------|
| **脱机作业（批处理作业）** | 不需用户干预，由系统根据作业说明书控制运行 |
| **联机作业（终端型作业）** | 用户通过终端打入键盘命令直接控制运行 |

### 3.5 作业输入/输出方式

| 方式 | 特点 |
|------|------|
| **联机 I/O** | 主机直接控制，CPU 与外围设备速度悬殊，利用率低 |
| **脱机 I/O** | 使用脱机外围设备解决速度差异 |
| **SPOOLing（假脱机）** | 利用共享高速磁盘模拟独占设备，使一台独占设备变成多台可并行的虚拟设备 |

**SPOOLing 系统组成**：常驻内存的 I/O 进程 + 输入井 + 输出井

### 3.6 作业控制块（JCB）

JCB 是作业存在的唯一标志，包含：

- **标识信息**：作业名、用户名、用户账号
- **状态信息**：提交、后备、执行、就绪、等待、完成
- **调度参数**：优先数、估计执行时间、作业类型
- **资源需求**：内存需求量、资源要求量
- **其他控制信息**

## 四、作业调度

### 4.1 三级调度

一个作业从提交到完成需经过**高级、中级和低级**三级调度。

### 4.2 调度算法评价因素

- **CPU 利用率**：通常 40%（轻负荷）~ 90%（重负荷），运行程序道数越多，CPU 空闲越低
- **吞吐量**：单位时间内 CPU 完成作业的数量
- **周转时间**：完成时间 − 提交时间
- **周转系数**：周转时间 / 执行时间
- **平均周转时间**：所有作业周转时间的平均值

### 4.3 四种常见调度算法

#### (1) 先来先服务（FCFS）
- 按作业进入系统的先后顺序调度
- 优点：实现简单、公平
- 缺点：未考虑资源利用率和作业特殊性；长作业在前则短作业等待时间很长

#### (2) 短作业优先（SJF）
- 以运行时间长短调度，优先选中短作业
- 优点：保证系统最大吞吐量，平均周转时间最短
- 缺点：不公平，长作业可能长期等待

#### (3) 响应比高者优先（HRN）

**响应比 = （1 + 等待时间） / 执行时间**

- 是 FCFS 和 SJF 的折衷
- 短作业因执行时间短而得到较高响应比
- 长作业随等待时间增加而提高响应比，不会无限等待
- 代价：每次调度需计算各作业响应比，有计算开销

#### (4) 优先级法

根据优先级选取作业，优先级可综合以下因素确定：
- 作业缓急程度
- 用户指定优先级
- 作业长短
- 等待时间
- 资源申请情况

> 优先级法可覆盖前三种算法，关键是合理设定优先级别。

## 五、用户界面（User Interface）

### 5.1 发展历程

| 阶段 | 特点 |
|------|------|
| **控制面板式** | 通过开关、板键、穿孔纸带输入，指示灯和打印机输出，人去适应计算机 |
| **字符用户界面** | 键盘输入字符，字符输出；功能强、灵活、屏幕开销少；但操作繁琐费时 |
| **图形用户界面（GUI）** | 支持文字、图形、声音、图像；操作自然方便；如 Windows、X Windows |
| **新一代用户界面** | 虚拟现实技术；以用户为中心、自然、高效、非精确、无地点限制 |

### 5.2 Windows 组成

| 组件 | 功能 |
|------|------|
| **KERNEL** | 内存管理、程序加载（含 DLL）、任务调度、文件管理 |
| **USER** | 窗口和消息管理，菜单、控件、对话框、定时器 |
| **GDI** (Graphic Device Interface) | 管理显示器和其他输出设备，为 USER 与应用程序提供设备无关接口 |

### 5.3 命令执行方式

- Apple Macintosh 首先推出**事件驱动控制方式**
- 外部触发被视为**事件**，通过**消息**告知系统
- 每个消息关联特定窗口，每个窗口有对应的"窗口过程"
- Windows 9x 使用**多消息队列**技术保证单个出错程序不会使整个系统死锁

### 5.4 界面管理功能

- 实现高效的人机通信
- 改善计算机的可用性、可学性和有效性
- 支持三维及多媒体技术
- 为不同应用提供多种界面构造工具及语言

## 六、用户管理和配置管理

系统管理员的主要工作：
- **用户账号管理**：添加或删除用户账号
- **用户监控**：监视控制用户活动
- **用户定制**：定制用户工作环境等

## 七、要点总结

| 主题 | 核心内容 |
|------|----------|
| **系统调用** | 用户态→核心态的桥梁，通过 trap/int 指令实现，与普通过程调用有本质区别 |
| **系统调用类型** | 进程控制、进程通信、存储管理、设备管理、文件保护、系统管理 |
| **作业概念** | 作业→作业步→进程，由程序+数据+作业说明书组成 |
| **SPOOLing** | 用磁盘模拟独占设备，实现虚拟设备并行 |
| **JCB** | 作业存在的唯一标志，含标识、状态、调度参数、资源需求 |
| **调度算法** | FCFS（简单公平）、SJF（最短平均周转）、HRN（折衷平衡）、优先级法（灵活可定制） |
| **评价指标** | CPU利用率、吞吐量、周转时间、周转系数 |
| **用户界面** | 控制面板→字符→GUI→虚拟现实 |
