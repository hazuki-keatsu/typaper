## 模糊集合与隶属函数

### 从精确到模糊

| 精确 | 模糊 |
| --- | --- |
| 答案确定：要么是，要么不是 | 答案不定：也许是、也许不是、介于之间 |
| 特征函数 f: A → {0, 1} | 隶属函数 μA: U → [0, 1] |

> 精确的数学语言和模糊的思维习惯之间存在矛盾。模糊逻辑由扎德（L. A. Zadeh）于1965年提出，用于处理现实世界因模糊而引起的不确定性。

### 模糊集合的定义

论域U中的**模糊集F**用一个在[0, 1]上取值的**隶属函数 μF** 来表示：μF: U → [0, 1]

- μF(u) 称为u对F的**隶属度**，值越大表示隶属程度越高
- 当 μF 的值仅为0或1时，模糊集退化为普通集合，隶属函数退化为特征函数

### 模糊集的表示方法

1. **扎德表示法**：F = Σ μF(ui) / ui
2. **序偶表示法**：F = {(μF(u1), u1), (μF(u2), u2), …}
3. **向量表示法**：F = {μF(u1), μF(u2), …, μF(un)}

### 相关概念

- **模糊支集**：μF(u) > 0 的所有元素构成的集合
- **交叉点**：μF(u) = 0.5 时的点
- **模糊单点**：模糊支集为单点且 μF(u) = 1.0

## 模糊集合的运算

设A、B是U上的两个模糊集：

| 运算 | 隶属函数 |
| --- | --- |
| **包含** (B ⊆ A) | μB(u) ≤ μA(u) |
| **并集** (A ∪ B) | μ(A∪B)(u) = max{μA(u), μB(u)} |
| **交集** (A ∩ B) | μ(A∩B)(u) = min{μA(u), μB(u)} |
| **补集** (¬A) | μ(¬A)(u) = 1 - μA(u) |

### 运算定律

满足幂等律、交换律、结合律、分配律、吸收律、两极律、复原律、摩根律。

## 模糊关系

### 模糊关系的定义

在 U1 × U2 × … × Un 上的一个n元模糊关系R是指以该笛卡尔积为论域的一个模糊集。

### 复合关系

设R1与R2分别是U×V与V×W上的模糊关系，复合关系 R1◦R2 是从U到W的模糊关系：

μ(R1◦R2)(u,w) = max_v{ min{μR1(u,v), μR2(v,w)} }

> 计算方法：取R1第i行与R2第j列逐个取小，再取最大值作为结果矩阵[i,j]元素。

## 模糊逻辑推理

### 模糊命题与知识表示

**模糊命题**：含有模糊概念、模糊数据的语句。
- 一般形式：x is A 或 x is A (CF)
- A是模糊概念，用模糊集及隶属函数刻画

**模糊产生式规则**：IF E THEN H (CF, λ)
- E：模糊条件；H：模糊结论
- CF：可信度因子；λ：匹配度阈值

### 模糊推理基本模式

| 模式 | 形式 |
| --- | --- |
| **广义取式假言推理 (GMP)** | 从 x is A' 推出 y is B' |
| **广义拒式假言推理 (GMT)** | 从 y is B' 推出 x is A' |
| **模糊三段论** | 从 A→B, B→C 推出 A→C |

### 合成推理规则（扎德方法）

对于知识 `IF x is A THEN y is B`：
1. 构造A与B之间的模糊关系R（极大极小规则）
2. 若证据为 x is A'，则 B' = A' ◦ R
3. 若证据为 y is B'，则 A' = R ◦ B'

### 模糊变换

**A ◦ R = B** 称为模糊变换，可用于模糊综合评价等场景。
