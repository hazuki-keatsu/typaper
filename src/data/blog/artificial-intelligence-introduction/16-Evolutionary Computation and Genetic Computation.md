## 进化算法原理

### 基本思想

生物种群的生存遵循达尔文**物竞天择、适者生存**的进化准则，通过选择、交叉、变异来适应环境。

### 四大典型范例

1. **遗传算法 (GA)**：Holland于1960s提出
2. **进化策略 (ES)**：Rechenberg和Schwefel于1960s提出
3. **进化编程 (EP)**：Fogel于1960s提出
4. **遗传编程 (GP)**：Koza于1990s创立

### 进化算法的特点

- 种群搜索策略和个体间信息交换是两大特点
- 不容易陷入局部最优，能以很大概率找到全局最优解
- 具有固有并行性，适合大规模并行计算
- 易于介入已有模型，具有可扩展性

---

## 进化算法框架

1. 产生包含N个个体(x1, x2, …, xN)的**初始群体**
2. 通过**选择算子**从群体中选择某些个体组成父代个体集
3. 利用**交叉算子**和**变异算子**对父代进行相关操作产生子代个体集
4. 将**替换算子**应用于旧群体和子代个体集，得到下一代群体
5. 反复迭代直至收敛于全局最优解或满意解

## 遗传算法

### 基本思想

遗传算法把问题的解表示成**"染色体"**（以一定方式编码的串），给出一群候选解，按适者生存原则选择、交叉、变异，一代代进化，最终收敛到最优解。

### 基本概念

| 术语 | 说明 |
| --- | --- |
| **串/染色体** | 个体形式，二进制串或其他编码串 |
| **种群** | 个体的集合 |
| **种群规模** | 种群中个体的数量 |
| **基因** | 串中的元素，表示个体的特征 |
| **适应度** | 个体对环境的适应程度 |

### 编码方法

| 方法 | 说明 |
| --- | --- |
| **二进制编码** | 使用{0,1}符号集，最常用。串长由搜索精度决定 |
| **浮点数编码** | 基因值用决策变量的真实值表示 |
| **符号编码** | 基因值取自一个无数值含义的符号集 |

### 遗传算子

**选择算子**：
- **赌轮选择**：个体被选中的概率与其适应度成正比
- **联赛选择**：随机选M个个体，取适应度最大者

**交叉算子**：以概率Pc交换配对个体的部分基因
- **一点交叉**：选择一个交叉点，交换右半部分
- **两点交叉**：选择两个交叉点，交换中间部分

**变异算子**：以概率Pm将某些基因值替换为其他值

### 控制参数

| 参数 | 推荐范围 |
| --- | --- |
| 种群规模 N | 30 ~ 160 |
| 交叉概率 Pc | 0.25 ~ 0.75 |
| 变异概率 Pm | 0.01 ~ 0.2 |

### 算法步骤

1. 初始化群体
2. 计算群体上每个个体的适应度值
3. 按适应度决定的规则选择进入下一代的个体
4. 按概率Pc进行交叉操作
5. 按概率Pm进行变异操作
6. 若未满足停止条件，转第2步；否则输出最优染色体

### 遗传算法的特点

- 从解的编码组（种群）开始而非从单个解开始搜索
- 利用适应度函数信息而非导数指导搜索
- 利用选择、交叉、变异等概率性算子进行随机操作
- 适用范围很广，不受连续、可微等条件约束
- 不容易陷入局部极值
