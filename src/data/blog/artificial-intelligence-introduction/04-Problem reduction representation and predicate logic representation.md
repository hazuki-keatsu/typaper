## 问题归约法

### 基本概念

**问题归约**是另一种基于状态空间的问题描述与求解方法：通过一系列变换将问题归约为一个子问题集合，这些子问题的解可以直接得到（本原问题），从而解决初始问题。

> 实质：从目标出发逆向推理，建立子问题层级，直到将初始问题归约为一个本原问题集合。

三个组成部分：
1. 初始问题描述
2. 将问题变换为子问题的操作符
3. 本原问题描述（不可再分解且直接可解）

### 与或图表示

- **与图**：将复杂问题分解为若干较简单的子问题
- **或图**：将原问题变换为若干较易求解的新问题

**可解节点**：
1. 终叶节点是可解节点（对应本原问题）
2. 含"或后继"的非终叶节点→至少一个后继可解即为可解
3. 含"与后继"的非终叶节点→全部后继可解才可解

**不可解节点**：
1. 无后裔的非终叶节点
2. 含"或后继"→全部后裔不可解才不可解
3. 含"与后继"→至少一个后裔不可解即为不可解

由可解节点构成、可推出初始节点为可解的子树称为**解树**。

## 谓词逻辑法

### 命题与谓词

**命题逻辑**只能进行命题间关系的推理，无法解决与命题结构和成分有关的推理问题。**谓词逻辑**在此基础上发展而来。

**命题**：具有真假意义的语句。不能同时为真又为假，但可在不同条件下不同取值。

**谓词**：用形如 `P(x1, x2, …, xn)` 的形式表述命题，分为**谓词名**（P，表示性质、状态或关系）和**个体**（x1, x2, …，独立存在的事物）。

> 当谓词中的变元都被特定的个体取代时，谓词就具有确定的真值"T"或"F"。

个体变元的取值范围称为**个体域**，可以是有限或无限的。

### 连词与量词

| 连词 | 符号 | 含义 |
| --- | --- | --- |
| 合取 | ∧ | 两个命题的"与"关系 |
| 析取 | ∨ | 两个命题的"或"关系 |
| 蕴涵 | → | "若P则Q" |
| 非 | ¬ | 否定 |
| 双条件 | ↔ | "当且仅当" |

| 量词 | 符号 | 含义 |
| --- | --- | --- |
| 全称量词 | ∀ | "所有的" |
| 存在量词 | ∃ | "至少存在一个" |

### 合式公式（WFF）

1. 原子谓词公式 P(t1, t2, …, tn) 是合式公式
2. 若A为合式公式，则¬A也是
3. 若A、B是合式公式，则A∨B、A∧B、A→B、A↔B也是
4. 若A是合式公式，x为自由变元，则(∀x)A和(∃x)A也是
5. 只有按上述规则求得的才是合式公式

### 等价关系

**狄·摩根定律**：¬(P∨Q) = ¬P∧¬Q；¬(P∧Q) = ¬P∨¬Q

**量词等价**：
- ¬(∃x)P(x) = (∀x)[¬P(x)]
- ¬(∀x)P(x) = (∃x)[¬P(x)]

**蕴涵等价**：P→Q = ¬P∨Q

**逆否率**：P→Q = ¬Q→¬P

### 置换与合一

**置换**：用变元、常量、函数替换变元，形如 {t1/x1, t2/x2, …}，不允许循环出现。

> 置换是可结合的，一般不可交换。

**合一**：寻找项对变量的置换，使两个表达式一致。若存在置换s使E1s = E2s = …，则称{ Ei }是可合一的，s为合一者。

### 谓词逻辑法的优缺点

**优点**：
1. 符号系统接近自然语言，直观自然
2. 真值只有"真"与"假"，表示精确
3. 知识与处理程序分离，模块性好，易于修改

**缺点**：
1. 只能表示确定性知识，无法处理不确定性
2. 缺乏知识组织原则，知识库管理困难
3. 推理时忽略语义信息，容易组合爆炸，效率低
