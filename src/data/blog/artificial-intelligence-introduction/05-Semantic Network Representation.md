## 语义网络法概述

**语义网络法**由奎廉（Quillian）于1968年提出，最初是联想记忆的心理学模型。1972年西蒙将其引入自然语言理解系统。

语义网络是**带标识的有向图**：节点表示事物、概念、属性、状态、事件、动作等（可嵌套形成子网络），弧表示节点间的语义关系。

最基本的语义单元用三元组表示为：**(结点1, 弧, 结点2)**，其有向图称为基本网元。

---

## 基本语义关系

| 类型 | 说明 | 常用关系 |
| --- | --- | --- |
| 类属关系 | 具体与抽象，实例/成员/分类 | **Is-a**, **A-member-of**, **A-kind-of** |
| 聚集关系 | 整体与部分 | **A-part-of** |
| 属性关系 | 对象与属性 | **Have**, **Can**, **Owner** |
| 推论关系 | 因果关系 | **Fetch** |
| 相近关系 | 形状/内容相似 | **Similar-to**, **Near-to** |
| 方位关系 | 位置关系 | **Located-on/under/inside/outside/at** |
| 时间关系 | 时间先后 | **Before**, **After** |
| 构成关系 | 一对多联系 | 无属性继承性 |

## 谓词逻辑与语义网络的等效性

语义网络的实质是将多元关系转化为二元关系的合取：

| 谓词逻辑 | 语义网络 |
| --- | --- |
| `MAN(LIMING)` | `LIMING --ISA--> MAN` |

---

## 语义网络的表示方法

### 一元关系

用 `P(x)` 表示。结点1为实体，结点2为属性，弧为语义关系。例如：动物能运动、会吃。

### 二元关系

用 `P(x, y)` 表示。复杂关系通过多个二元/一元关系组合实现。例如：鸟是一种动物，鸟有翅膀、会飞。

### 多元关系

将多元关系 `R(X1, …, Xn)` 转化为二元关系的合取：
> `R(X1, …, Xn)` → `R12(X1, X2) ∧ R13(X1, X3) ∧ … ∧ R1n(X1, Xn)`

也可引入**情况节点**或**动作节点**来直观表示。例如三元关系"小王给小林一本书"通过GIVE动作节点连接"小王-施事"、"小琳-受事"、"书-客体"。

---

## 连接词和量词的表示

### 合取与析取

通过**合取节点**和**析取节点**实现。

### 否定

- 基本语义关系否定：直接在弧上标注 ¬
- 一般语义关系否定：引入"非"节点

### 蕴含

通过**蕴含关系节点**实现，包含 **ANTE**（前提条件）和 **CONSE**（结论）两条弧。

### 量词

- **存在量词**：直接用 ISA、AKO 等表示
- **全称量词**：引入**子空间**（超结点），每个子空间为一个子命题

---

## 语义网络的推理过程

推理方式：**继承**和**匹配**。

### 继承

将描述沿 **ISA**、**AKO** 弧从类节点传递到实例节点。三种方式：

| 方式 | 说明 |
| --- | --- |
| **值继承** | 沿ISA/AKO链直接传递属性值 |
| **if-needed继承** | 槽值未知时通过程序计算（如由体积和密度算重量） |
| **缺省继承** | 不确定但相当可能的值，如"法官通常是诚实的" |

### 匹配

在知识库中寻找与待求解问题相符的语义网络模式，可通过**虚链**和**虚节点**实现结构对应。

---

## 优点与不足

**优点**：
1. **结构性**：属性与语义联系显式表示，下层节点可继承、新增或变异上层属性
2. **联想性**：源于人类联想记忆模型，体现联想思维
3. **自索引性**：通过弧可直接找到相关信息，避免全库搜索
4. **自然性**：带标识有向图直观，与自然语言转换容易

**不足**：
1. **非严格性**：无严格形式化体系，推理正确性依赖处理程序
2. **复杂性**：表示手段多样，灵活性高但处理一致性问题
