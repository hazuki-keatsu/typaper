## 搜索的基本概念

**搜索**：根据已有的知识以及问题的实际情况，不断寻找可利用知识，从而构造一条代价最小的推理路线，使问题得以解决的过程。

> 搜索的本质：从隐式的状态空间图中不断生成显示的搜索图和搜索树，最终找到路径的过程。

搜索适用于：
1. 不良结构或非结构化问题
2. 难以获得求解所需的全部信息
3. 没有现成的算法可供求解使用

### 搜索的类型

按是否使用启发式信息：
- **盲目搜索**：按预定的控制策略进行搜索，获得的中间信息不改变控制策略
- **启发式搜索**：加入与问题有关的启发性信息，指导搜索朝着最有希望的方向前进

按问题的表示方式：
- **状态空间搜索**：用状态空间法求解问题
- **与或树搜索**：用问题归约法求解问题

## 状态空间的搜索策略

### 基本思想

1. 把问题的初始状态作为当前扩展节点进行扩展，生成一组子节点
2. 检查目标状态是否出现在这些子节点中。若出现，则搜索成功
3. 若没出现，按某种搜索策略从已生成的子节点中选择一个节点作为当前扩展节点
4. 重复上述过程，直到目标状态出现在子节点中或没有可供操作的节点为止

> "扩展"是指对该节点用某个可用操作进行作用，生成该节点的一组子节点。

### 数据结构

| 字段 | 说明 |
| --- | --- |
| STATE | 节点所表示状态的基本信息 |
| PARENT NODE | 指向当前节点的父节点的指针 |
| ACTION | 从父节点转换为当前节点所使用的操作 |
| DEPTH | 当前节点在搜索树中的深度 |
| PATH COST | 从起始节点到当前节点的路径代价 |

### 符号约定

- **OPEN表**：未扩展节点表，存放刚生成的节点
- **CLOSED表**：已扩展节点表，存放已经扩展或将要扩展的节点
- **S**：问题的初始状态
- **G**：搜索过程所得到的搜索图
- **M**：当前扩展节点新生成的且不为自己先辈的子节点集

## 图搜索的一般过程

1. 把初始节点S放入OPEN表，建立目前仅包含S的图G
2. 检查OPEN表是否为空，若为空，则问题无解，失败退出
3. 把OPEN表的第一个节点取出放入CLOSED表，记该节点为n
4. 考察节点n是否为目标节点。若是，则成功退出，解为追踪图G中沿着指针从n到S的路径
5. 扩展节点n，生成一组子节点。把不是n先辈的子节点记入集合M，并加入G中
6. 针对M中子节点的不同情况，分别处理：
   - 未在G中出现过的M成员：设置指向父节点n的指针，放入OPEN表
   - 已在G中出现过但未扩展的M成员：确定是否需要修改指向父节点的指针
   - 已在G中出现过且已扩展的M成员：确定是否需要修改其后继节点指向父节点的指针
7. 按某种策略对OPEN表中的节点进行排序
8. 转第2步

> 各种搜索策略的主要区别在于对OPEN表中节点的排列顺序不同。广度优先搜索把先生成的子节点排在前面，深度优先搜索则把后生成的子节点排在前面。
